    How to play

    Work together to help the guesser find the secret word.

    1. Each round, one player is the guesser. Everyone else sees the secret word.
    2. Each clue giver sends one word that hints at the secret word. Only the first word counts.
    3. Clues that match each other, or the secret word, are crossed out so the guesser can't see them.
    4. The guesser uses the remaining clues to guess the word. Each correct guess scores a point.
    5. The guesser rotates each round, for up to 13 rounds.

    You need at least 3 players. The host chooses the settings and starts the game.
